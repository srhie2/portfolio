Projects

DonkeyCar Vision Control

A DSC190 team project testing camera-based line and lane following with Python, OpenCV, and PID control. My work focused on the single-line follower and physical testing. The line follower completed three consecutive laps on our course track.
View project on GitHub

Income and Voter Participation

A COGS108 team project studying the association between neighborhood income and voter participation in California in 2022 and 2024. I contributed to research question design and data curation.
View project on GitHub

League of Legends Match Analysis

A DSC80 course project analyzing professional League of Legends match data with pandas and Plotly. I explored missing data, hypothesis testing, and match-outcome classification using logistic regression and gradient boosting.
View project on GitHub
